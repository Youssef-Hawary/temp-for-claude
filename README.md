# Hawary's Guides: WoW Forever

Class guides for WoW Forever, from character creation to level 60 endgame.

| Guide | What's inside |
|---|---|
| [Paladin](paladin.html) | Ret, Prot, Holy and Shockadin builds, S/A/B/C ratings, macros, gear, leveling |
| [Warlock](warlock.html) | Leveling, demons, builds, macros, gear |
| [Hunter](hunter.html) | Leveling, pets, builds, macros, gear |

Each guide is one self-contained HTML file. Open it in any browser, on phone or desktop. Every guide has tabs, search, and a "Stuck? Help" window.

Builds and ratings change as patches land. Each guide lists its sources at the bottom.
